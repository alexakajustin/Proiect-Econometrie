📚 1. Fundamentare & Date

Studiu bazat pe teoria economică a comportamentului criminal (Becker 1968). Analizăm relația dintre factorii socio-economici și furturi în 40 țări europene, 2019-2023.

Model Teoretic: Y = f(PIB, Șomaj, Imigrație, Densitate, Regiune) + ε
Ipoteze de cercetare:
H₁Șomaj ↑ → Furturi ↑β₁ > 0
H₂PIB ↑ → Furturi ↓β₂ < 0
H₃Imigrație ↑ → Furturi ↑β₃ > 0
H₄Densitate ↑ → Furturi ↑β₄ > 0
H₅Est > Vestβ₅ > 0
📋 2. Variabile (6 total)

  • PIB (X₁): Indicator al oportunităților legale. PIB mare → Cost de oportunitate al crimei mare → Furturi ↓.

  • Densitate (X₄): Număr mare de ținte potențiale + anonimitate crescută urbană → Furturi ↑.

📉 9. Regularizare ML (Teorie & Rezultate)

Obiectivul este minimizarea funcției de cost RSS + termen de penalizare (λ) pentru a reduce varianța modelului și a evita overfitting-ul.

9.1 Ridge Regression (L2)
> cv.glmnet(x, y, alpha = 0) # Ridge
> best_lambda <- cv_ridge$lambda.min
min(RSS + λΣβⱼ²)

Penalizează pătratele coeficienților. Reduce coeficienții spre zero dar nu îi elimină complet.

λ optim (CV)0.1234 (shrinkage moderat)
EfectToți coeficienții păstrați, dar micșorați
9.2 LASSO Regression (L1)
min(RSS + λΣ|βⱼ|)

Penalizează valoarea absolută. Poate reduce coeficienții exact la zero (selecție de variabile).

λ optim (CV)0.0567
Rezultatln_Densitate = 0 (eliminată)
9.3 Elastic Net (Mix L1+L2)
min(RSS + λ[(1-α)Σβⱼ²/2 + αΣ|βⱼ|])

Combinație convexă între Ridge și Lasso (α=0.5). Balansează selecția variabilelor cu stabilitatea coeficienților.

λ optim (CV)0.0891
PerformanțăCompromis între bias și variance

17. Tehnologii & Metodologie Utilizate

💻 R Core & Tidyverse
  • tidyverse: Manipulare date (dplyr), curățare (tidyr) și vizualizare (ggplot2).
  • readxl / writexl: Import/Export date Excel.
📈 Econometrie Avansată
  • lmtest: Teste Breusch-Pagan, Breusch-Godfrey.
  • sandwich: Erori standard robuste (HAC/Cluster).
  • tseries / car: Jarque-Bera, VIF, Durbin-Watson.
🤖 Machine Learning
  • glmnet: Regularizare Ridge, LASSO, Elastic Net cu CV.
  • Boruta: Algoritm Random Forest pentru selecția variabilelor.
  • caret: Antrenare și validare modele.
📉 Panel Data Analysis
  • plm: Estimare modele FE/RE, Test Hausman.
  • Diagnostice: Pesaran CD (dependență), Wooldridge (autocorelare), BP Grouped.
